# 使用手冊（精簡版）

給學校職員與導師。頁面請用 http 開（`serve.cmd` 或 VS Code Live Server），不要用 file://。

用 `serve.cmd` 開：資料存在**本資料夾**的 `local-state.json`，每個資料夾各自一份（演示、真實各開各的，互不干擾）。用 Live Server 開：資料存在瀏覽器，同一網址的資料夾共用。第一次用 serve.cmd 開時若瀏覽器留有舊資料，會問要不要搬進本資料夾。

## 一、開始前（只做一次）

| 步驟 | 在哪 | 做什麼 |
|---|---|---|
| 1 | 設定 → 導師 | 新增導師；每位貼上自己的 Google 日曆 ID，按「測試」確認讀得到 |
| 2 | 學生名單庫 | 新增學生／小組：導師、星期、時間、時長、費率。只上小組的學生取消勾選「有常規私教課」，只勾所屬小組 |
| 3 | 設定 → Google Calendar | 填 OAuth Client ID、預設日曆 ID。「授權寫入」關＝**唯讀模式**（預設），開＝**讀寫模式**。選「兩邊都改了時以哪邊為準」 |
| 4 | 頂部 | 「全量備份 (JSON)」隨時可備份；「撤銷」退回上一步 |

## 二、每月流程（兩種模式相同）

| 順序 | 按鈕 | 功能 |
|---|---|---|
| 1 | 全校時間表 → 選月份 → 生成 | 按學生固定時段排出整月常規課 |
| 2 | 📋 清單／📅 月曆 | 檢查課表；同導師同時段撞課會標黃。選導師 → 學生下拉只列他的學生；選學生 → 導師自動跟隨，月曆與週次下拉只列該生有課的星期 |
| 3 | 放進 Google Calendar | 讀寫：同步 GCal 推送。唯讀：導出 .ics 再匯入。細節見三、四 |
| 4 | 平時處理請假／缺席／改期／補堂 | 在系統或 Calendar 做都可以。細節見三、四 |
| 5 | 同步 GCal | 比對兩邊差異，勾選後執行，兩邊一致 |
| 6 | 發送中心 | WhatsApp 發請假確認／補堂確認／改期通知 |
| 7 | 批量確認出席 | 已過時間、仍是已排課的課標出席。不會推到 Calendar |
| 8 | 出席與繳費、高級薪酬管理 | 收費與糧單 |

## 三、讀寫模式（授權寫入＝開）

系統可以直接改 Calendar。每節課一個事件，推到該導師的日曆。

| 我想 | 在系統做 | Calendar 那邊 |
|---|---|---|
| 整月放進 Calendar | 同步 GCal → 勾「⬆️ 推送」→ 執行勾選項目 | 自動建立 |
| 請假／缺席 | 課卡「請假」或「NS」→ 按「寫回 GCal 狀態」 | 事件自動寫上 狀態：L／NS |
| 改期、排補堂 | 改期或排補堂後，彈窗頂部「同步到 Google Calendar 嗎？」按一下 | 改原事件或建新事件，不會重複 |
| 取消補堂 | 課卡「取消補堂」 | 事件留著，下次同步在「🧹 殘留」勾掉 |
| 在 Calendar 直接建補堂 | 待補堂池「複製標題」「複製內容」→ 貼到新事件；同步 GCal → 「➕ 手動新建」選「作為補堂 ←」 | 系統連上這個事件，不另建 |
| 在 Calendar 改了（拖時間、填狀態、手動建課） | 同步 GCal → 勾選拉回 | — |

待補堂池（已請假、還沒排補堂的課）在總課表頁月曆／清單的下面，預設展開；點標題可收起。頁面頂部的「辦理補堂/請假」卡可以點，直接跳到待補堂池（沒有待補的就列出本月的請假與補堂）。

撞堂：點頂部的「時間衝突/撞堂警報」卡（或課表上方撞堂提示裡的「只看撞堂的課」），清單會只列撞堂的課，按「誰和誰重疊」分組；每組把其中一節按「改期」移走即可，全部解決後按「顯示所有課堂」。課表篩選列的「所有課堂／請假與補堂／⚠️ 撞堂」下拉是同一個功能。

小組課改期是整節的事：按小組卡頭的「全組改期」，仍是已排課的成員一起搬到新時段（已請假的不動），每位成員各有一筆改期通知，Calendar 上仍是同一個事件。整組一起補的補堂也一樣，在卡頭按「全組改期」或請假那張卡的「全組改期補堂」。成員那一行不再有改期鈕；真的要只動一位（修資料），開「手動模式」。改期時的撞堂提示只列新時段真的撞到的課，請假的課不佔時段。

畫面右下角有一顆懸浮的「GCal」圓形按鈕，和總課表頂部的「同步 GCal」是同一個功能，任何頁籤、滑到哪裡都按得到；按住可以拖到別的位置（位置記在這個瀏覽器）。批量推送／刪除會同時送幾件（預設 6，設定 → Google Calendar「批量推送／刪除時同時送幾件」可改，1–10），整月四五十節幾秒內完成；送太密被 Google 暫時擋下時會自動等一下再試。

同步面板各組：⬆️ 推送、🔁 本地改期、📦 搬到導師的日曆、📤 寫回狀態、🕒 時間變更、🏷️ 狀態碼變更、🗑️ 已刪除、🧹 殘留、➕ 手動新建。預設勾選＝執行後兩邊一致。每組可按標題收起（收起不影響勾選，標題右邊顯示「已勾 x／n」），標題右邊有該組的「全選／全不選」；面板頂部固定著一排按鈕（清單再長也不用滑到底）：「全選／全不選」管全部，「全部收起／展開」一次收放所有組，右邊是「取消」「執行勾選項目」。兩邊都改了時，按設定「以哪邊為準」。⚠️ 狀態衝突（系統已出席、Calendar 填了請假／缺席）預設不勾，先查清楚。

## 四、唯讀模式（授權寫入＝關）

系統只讀 Calendar，不會改。Calendar 那邊要人手做；系統按事件標題（學號／姓名／小組名）認課。

| 我想 | 在系統做 | 然後在 Calendar 人手做 |
|---|---|---|
| 整月放進 Calendar | 導出 .ics（每位導師一個檔） | Google 日曆 → 設定 → 匯入，選該導師的日曆 |
| 請假／缺席 | 課卡「請假」或「NS」→「在 GCal 填 狀態：L」 | 打開的事件說明欄填 L／SL／TL／NS，儲存 |
| 改期 | 改期 → 「改 GCal 舊事件（舊 → 新）」 | 打開的事件把時間改成新的，不要另建 |
| 排補堂 | 排補堂 → 「加進 GCal」 | 已填好的新建頁，「日曆」欄選該導師的日曆，儲存 |
| 取消補堂 | 取消補堂 | 打開的事件按刪除 |
| 在 Calendar 直接建補堂 | 待補堂池「複製標題」「複製內容」；之後同步 → 「➕ 手動新建」選「作為補堂 ←」 | 在該導師的日曆新建事件，貼上標題與說明，填時間 |
| 直接在 Calendar 改 | — | 拖時間；說明欄「狀態：」填碼；補堂可直接建事件 |
| 拉回本地 | 同步 GCal（唯讀）或 匯入 ICS → 勾選執行 | — |

面板裡「📌 請到 Calendar 改」「📝 請到 Calendar 填」＝還沒人手做的項目，做好再同步就消失。

## 五、狀態碼（Calendar 說明欄「狀態：」那一行）

| 碼 | 意思 |
|---|---|
| 留空 | 沒填。系統不動它；出席在系統「批量確認出席」即可，不用寫回 |
| A | 出席 |
| L／SL／TL | 事假／病假／導師請假 |
| NS | 缺席 |
| MU | 補堂標記，不是狀態 |

中文也認：出席、請假、病假、導師請假、缺席。

## 六、重來

設定 → 危險區：「清空本月」「全部清場」清 Calendar 帶標籤事件＋本地（唯讀模式只清本地）；「強制清空」刪日曆所有事件，debug 用。按之前先「全量備份」。

## 七、換成真實名單

1. 用真實的 `data.js` 覆蓋演示版（不要提交進 git：`git update-index --skip-worktree data.js`）。
2. 設定 → 危險區「從 data.js 重新載入名單」：學生、小組班、導師都重讀。頁面平時只讀 localStorage，不按這個不會生效。
3. 「全部清場」清掉演示課表，再「生成」。
4. 設定頁填機構資料：FPS、網址、學費單尾段、Google Client ID、各導師日曆 ID。
5. 想回到演示情境：設定 → 危險區「還原演示名單」（讀 `demo_data.js`），再「全部清場」→「生成」。之後「從 data.js 重新載入名單」即換回真實名單；導師日曆 ID 兩邊都記住，不用重填。


## 八、長假（停課）與學號寫法

**長假**：學生名單 → 編輯 → 最下面「長假／停課」→「＋ 新增長假」。

- 開始日期＝第一天不上課；復課日期＝當天起恢復上課。
- 復課日期留空＝未定：之後生成的每個月都略過這位學生，回來時再填上復課日期。
- 長假內的日子生成時不出課：不收學費、不佔時段、不推 Calendar。精確到日，月中開始或月中復課只略過那幾天。
- 小組成員放長假：只略過他那幾天，其他成員照常，小組收費不變。
- 名單上會標「長假中」或「將放長假」；生成勾選區標出本月略過幾堂；生成完成的提示列出略過的學生。
- 已經生成好的月份：改了長假後，到該月勾選這位學生再按一次「生成」。長假內仍是「已排課」的課會刪掉，復課後的課會補上，學費條目跟著更新。已推到 Calendar 的課，下次「同步 GCal」會列出要刪的事件（唯讀模式要自己到 Calendar 刪）。

**學號寫法**：前面補不補零都算同一號，英文字母不分大小寫。例如 32、032、0032 是同一位學生。

- Calendar 事件標題用「32 陳大文」或「032陳大文」開頭，同步時也認得是 0032。
- 以時間或日期開頭的標題（如「15:00 …」「10/07 …」）不會被當成學號。
- 新增學生時，學號與現有學生同號會被擋下。
- 搜尋框輸入 32 或 0032 都找得到。
