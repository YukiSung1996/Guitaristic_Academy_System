# Demo Music Studio 脫敏測試版

這是用於開發、測試和演示的通用脫敏版本，不代表任何真實機構或客戶。

## 運行

直接開啟 `index.html`，或使用 VS Code Live Server。所有資料均為虛構測試資料，只保存於瀏覽器 `localStorage`，不會改動其他版本。

## 脫敏聲明

- 不包含真實學生、導師、電話、電郵、機構名稱或客戶識別資料。
- 測試電郵只使用 `example.com`，電話使用零佔位號碼。
- 不包含地區或真實貨幣標識；金額僅作為無貨幣單位的演示數值。
- 請勿在此目錄放入真實客戶資料，也不要把此版本當作生產資料庫。

## 功能（v2）

- 脫敏學生測試資料和學生 CRUD
- 總課表持久化（`gac_lessons_v2` 按月分桶）；重新生成為 merge 語義，已有狀態不會被清空
- 課堂狀態機：已排課／已上課／請假（事假 L、病假 SL、導師請假 TL）／NoShow；非法轉換被攔截，批量確認出席
- 請假與補堂兩步解耦：先標記請假，隨時從「待補堂池」（跨月、按等待天數排序）安排補堂；防重複排堂
- 補堂可倒回：還原「已排補堂的請假」會級聯確認並一併取消補堂；請假行內可直接「改期補堂／取消補堂」
- 小組課防護：TL 導師請假全組聯動；補堂時段發散攔截與總表頂部不一致警告橫幅；同一導師時間重疊（撞堂）檢測，小組同時段豁免
- 手動模式：跳過狀態機限制直接改狀態、不觸發小組聯動（每次載入預設關閉，用於修正誤操作）
- 發送中心：學費、請假確認、補堂確認訊息雙欄管理（待發送／已發送，按月獨立）；開 WhatsApp 不會自動移欄，需手動「標記已發」；亦可「手動已發」與「移回待發」；無電話學生僅可複製或手動已發；學費金額可行內手改（重新生成不覆蓋）
- 設定頁：NOSHOW 是否計薪、公開 ICS 網址、Google Calendar OAuth 參數（Phase 2 使用）
- 薪酬按實際上課（ATTENDED）統計，補堂按實際上課日期歸屬月份；NOSHOW 計薪依設定
- 月曆／週曆視圖、單堂 Google Calendar 預填連結和整月 ICS 導出（VEVENT 含 `UID:<lessonId>@guitaristic`）
- WhatsApp Web 預填訊息連結（只使用演示電話號碼）
- 全量 JSON 備份／還原（學生＋課表＋發送紀錄＋設定，帶 schema 版本檢查；舊版「僅學生名單」備份檔兼容匯入）

## 文件

- `index.html`：頁面與六個功能頁籤（總課表／單一學生／學生名單庫／高級薪酬／發送中心／設定）
- `data.js`、`art-rate-data.js`：課程選項、測試資料、費率與日曆狀態碼
- `state.js`：頁面內存狀態
- `app.js`：排堂、狀態機 UI、待補堂池、小組防護、發送中心、備份還原
- `payroll-advanced.js`：高級薪酬計算
- `lib/`：無 DOM 依賴的純函數庫（`schedule.js` 生成與 merge、`lessonState.js` 狀態機與補堂鏈、`payroll.js` 計薪、`sendlog.js` 發送紀錄、`storage.js` 持久化與備份）
- `tests/`：Node 內建 test runner 的單元測試
- `styles.css`：頁面樣式

## 測試

無需安裝 Node：倉庫附帶便攜版（`.tools\node\`，已被 gitignore）。

```
run-tests.cmd
```

或手動執行：

```
.tools\node\node.exe --test "tests/*.test.js"
```
