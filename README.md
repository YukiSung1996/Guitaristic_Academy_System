# Demo Music Studio 脱敏测试版

这是用于开发、测试和演示的通用脱敏版本，不代表任何真实机构或客户。

## 运行

直接打开 `index.html`，或使用 VS Code Live Server。所有资料均为虚构测试资料，只保存于浏览器 `localStorage`，不会改动其他版本。

## 脱敏声明

- 不包含真实学生、导师、电话、电邮、机构名称或客户识别资料。
- 测试电邮只使用 `example.com`，电话使用零占位号码。
- 不包含地区或真实货币标识；金额仅作为无货币单位的演示数值。
- 请勿在此目录放入真实客户资料，也不要把此版本当作生产资料库。

## 功能

- 脱敏学生测试资料和学生 CRUD
- 按月份、固定星期和时间生成课堂
- 同一导师的时间重叠检测
- 正常、请假、补堂、No Show 状态切换
- 按有效堂数、课时和导师拆帐比例计算薪酬
- 同时显示学生明细及按导师汇总的堂数、课程总额和导师应得
- 月历视图、单堂 Google Calendar 预填链接和整月 ICS 导出
- WhatsApp Web 预填消息链接（只使用演示电话号码）
- JSON 导出和恢复测试资料

## 文件

- `index.html`：页面和三个功能页签
- `data.js`：课程选项、测试资料和费率规则
- `state.js`：localStorage 状态
- `app.js`：排堂、撞堂、CRUD 和薪酬计算
- `styles.css`：页面样式

## 验证结果

2026-09-14 浏览器验证通过：6 名学生初始化、10 堂月课生成、10 个冲突事件识别、请假扣除、60% 拆帐重算、学生新增、刷新持久化、恢复默认资料，以及 Instructor A / Instructor B 分导师薪酬汇总。
